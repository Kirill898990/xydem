# Руккола в эко-боксах — проект 6 класса

Проект для республиканской научно-практической конференции «АгроБудущее: идеи школьников» (секция «Растениеводство»).

**Сайт проекта:** https://kirill898990.github.io/xydem/
На сайте можно поиграть в «Гидро-огород» в браузере и скачать игру для Android.

## Что здесь лежит

| Папка / файл | Что это |
| --- | --- |
| `docs/index.html` | Сайт-визитка о рукколе (публикуется на GitHub Pages) |
| `docs/game/index.html` | Игра «Гидро-огород»: выбери растение и вырасти его на гидропонике |
| `docs/gidro-ogorod.apk` | Та же игра для телефонов на Android (Android 8.0 и новее) |
| `project/Проектная_работа_Руккола_в_эко-боксах.docx` | Проектная работа по требованиям Положения: титульный лист по образцу, содержание, введение, 2 главы, заключение, список литературы, 4 приложения |
| `project/Заявка_АгроБудущее.docx` | Заявка на участие (Приложение 1 к Положению) |
| `android/` | Исходники Android-приложения |

## Как включить сайт (один раз)

1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. В поле **Branch** выберите основную ветку и папку **/docs**, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу https://kirill898990.github.io/xydem/.

После этого сайт обновляется сам при каждом изменении файлов в папке `docs/`.

## Важно перед сдачей работы

В .docx **жёлтым выделено** то, что нужно заменить своими данными: имена, класс, кружок, город, даты, цены
и **все результаты измерений** (таблицы 4–6, рисунок 2, выводы). Сейчас там стоят примерные значения,
чтобы было видно, как оформить работу. Работу с выдуманными цифрами сдавать нельзя: жюри проверяет,
что исследование настоящее.

Как обновить цифры автоматически:

1. Впишите свои измерения в `project/src/data.js`.
2. Запустите `project/src/make.sh`: пересоберутся график, таблицы, расчёты и оглавление.

## Игра «Гидро-огород»

- 5 растений с настоящими параметрами: руккола, кресс-салат, листовой салат, базилик, шпинат.
- Растение растёт в реальном времени. Для показа есть ускоренный режим (1 игровой день = 1 минута).
- Ребусы, загадки и викторина о гидропонике дают «листики», за них покупаются улучшения огорода.

Установка на Android: скачайте `gidro-ogorod.apk` с сайта, откройте файл и разрешите установку из этого источника.

Пересборка APK (нужен Android SDK, platform 35):

```bash
cd android
./gradlew assembleDebug
```

Перед сборкой игра из `docs/game/index.html` автоматически копируется в приложение.
