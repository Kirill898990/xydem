# Руккола в эко-боксах — проект 6 класса

Проект для республиканской научно-практической конференции «АгроБудущее: идеи школьников» (секция «Растениеводство»).

## Что здесь лежит

| Папка / файл | Что это |
| --- | --- |
| `project/Проектная_работа_Руккола_в_эко-боксах.docx` | Проектная работа по требованиям Положения: титульный лист по образцу, содержание, введение, 2 главы, заключение, список литературы, 4 приложения. Times New Roman 14, интервал 1,5, поля 20/10/20/20 мм, нумерация страниц |
| `project/Заявка_АгроБудущее.docx` | Заявка на участие (Приложение 1 к Положению) |
| `site/index.html` | Сайт-визитка о рукколе |
| `game/index.html` | Игра «Гидро-огород» (работает в браузере) |
| `apk/gidro-ogorod.apk` | Та же игра для телефонов на Android (Android 8.0 и новее) |
| `android/` | Исходники Android-приложения |

## Важно перед сдачей работы

В .docx **жёлтым выделено** то, что нужно заменить своими данными: имена, класс, кружок, город, даты, цены
и **все результаты измерений** (таблицы 4–6, рисунок 2, выводы). Сейчас там стоят примерные значения,
чтобы было видно, как оформить работу. Работу с выдуманными цифрами сдавать нельзя: жюри проверяет,
что исследование настоящее.

Как обновить цифры автоматически:

1. Впишите свои измерения в `project/src/data.js`.
2. Запустите `project/src/make.sh`: пересоберутся график, таблицы, расчёты и оглавление.

Нужны Node.js (пакеты `docx`, `playwright`), LibreOffice и poppler-utils. Можно править и прямо в Word,
но тогда график (рисунок 2) нужно перестроить вручную.

## Как установить игру на Android

1. Скачайте на телефон файл `apk/gidro-ogorod.apk`.
2. Откройте его и разрешите установку из этого источника.
3. Значок «Гидро-огород» появится на рабочем столе.

## Как пересобрать APK

```bash
cd android
./gradlew assembleDebug
```

Нужен Android SDK (platform 35). Перед сборкой игра из `game/index.html` автоматически копируется
в приложение. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.
